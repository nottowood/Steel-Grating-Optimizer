# SGO v1.2.1 — RELEASE NOTES

**Release Date:** 2026-06-22
**Type:** Feature Release + Deployment Readiness
**Branch:** v1.1.0-dev

---

## New Features

### PDF Export — Production Cutting Plan

Generate a professional A4 PDF document containing:

- **Page 1:** Executive Summary
  - Document metadata (project name, date, version, algorithm)
  - Project KPI (Sold Area, Production Area, Raw Material Area, Yield, Scrap)
  - Packing KPI (Stock Bars Required/Saved, Utilization)
  - Recovery KPI (when available)
- **Pages 2+:** Production Cutting Plan with color-coded remnant classification
- **Final Page:** Material Flow Summary + Validation R22-R29

Footer: "Generated by SGO v1.2.1" on every page.

### Excel Export — Production Cutting Plan

Generate a multi-sheet XLSX workbook containing:

- **Sheet 1:** Executive Summary (metadata + all KPIs)
- **Sheet 2:** Production Cutting Plan (table format)
- **Sheet 3:** Material Summary (area breakdown)
- **Sheet 4:** Validation R22-R29 with PASS/FAIL highlighting
